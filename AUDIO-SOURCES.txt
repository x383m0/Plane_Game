WINGS ARENA — AUDIO SOURCES

The current audio pass is intentionally modular so individual sounds can be
replaced later without changing game logic.

Gun sound:
- a10-gun-burst.ogg -> a 0.98-second excerpt (source time 0.43–1.41 s) from
  the user-supplied BRRRRRRT.wav, covering the initial A-10 cannon firing
  burst. It loops only while gunfire is active.

Flight audio remains disabled: no engine, boost, or flyby sound is loaded.

Temporary combat effects from the uploaded sndfx.zip / War on Water: SNDFX:
- Airplanes/aiplaneexplode.ogg -> audio/airplane-explosion.ogg
- Guns/torpedo1.ogg -> audio/missile-launch.ogg
- Guns/gun2Heavy.ogg -> audio/heavy-impact.ogg
- Guns/throwgrenade.ogg -> audio/flare.ogg
- Interface/callhelp.ogg -> audio/lock-alarm.ogg

These temporary effects can be replaced later by swapping files with the same
filenames, without editing game.js.
